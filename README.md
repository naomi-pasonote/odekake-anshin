# おでかけ安心

予定が決まった時点から、当日の準備・移動までに必要な情報を一か所で確認できる生活サポートWebアプリです。

## デモ

https://odekake-anshin-naomi.firebaseapp.com/

※利用にはログインが必要です。

## 目的

予定、場所、移動、持ち物などが別々に管理される負担を減らし、「忘れないように頑張る」のではなく、アプリで確認しながら安心して外出準備ができることを目指しています。

## 主な機能

- 月間カレンダーと予定管理
- 今日の予定・準備状況の確認
- 予定ごとの日時・場所・参加者・連絡先・予約情報
- 持ち物・手土産・コーディネートの管理
- Googleカレンダー連携
- Googleマップへのリンク
- 交通・乗換情報の管理
- AIによる準備サポート
- PC・スマートフォン対応

## 技術

React / TypeScript / Vite / Firebase Authentication / Firestore / Firebase Hosting
